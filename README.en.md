# interview-review-skill

Turn interview transcripts into a structured Markdown review document — question list, question intent, result analysis, error correction, and interview summary.

## What the skill does

When invoked, the skill runs 4 steps:

| Step | What it does | What you get |
| --- | --- | --- |
| **Step 1** | Parse the raw transcript → extract Q&A pairs | Every question extracted |
| **Step 2** | Judge answer correctness (technical accuracy / completeness / communication) | Whether each answer was correct |
| **Step 3** | Analyze the deeper intent behind each question (using the `deep-dive.md` framework) | The question behind the question |
| **Step 4** | Correct wrong answers + provide model responses | Correct answers for missed questions |

## Output structure

The final output is a Markdown document with 5 modules:

1. **Question list** — every question extracted from the interview, numbered in order.
2. **Question intent** — for each key question: what it was testing, the deeper intent, and what a strong answer would cover.
3. **Result analysis** — accuracy rate, per-dimension scores (technical depth / problem solving / system design / communication), and a strengths-and-weaknesses summary.
4. **Error correction** — original answer → what went wrong → correct answer → improvement tips.
5. **Interview summary** — branches by interview type:
   - Technical interview → **"What to focus on" (To-Learn List)**: specific topics this interview exposed, grouped by theme.
   - HR / behavioral interview → **"Overall advice"**: personalized, actionable numbered suggestions.
   - Mixed interview → both sections.
