# interview-review-skill
用于面试复盘：将面试文字稿转换成 Markdown 格式的结构化的复盘文档 —— 问题列表、问题深意、面试结果分析、错误答案纠正、面试总结

## 技能能力概览
这个 Skill 被调用后，会执行 4 个步骤：

| 步骤 | 做什么 | 对应你需求 |
|---|---|---|
| **Step 1** | 解析原始对话文本 → 提取 Q&A 对 | 提取所有问题 |
| **Step 2** | 判断答案正确性（技术准确度 / 完整性 / 表达） | 判断回答是否正确 |
| **Step 3** | 分析问题深层意图（参考 `deep-dive.md` 框架） | 探索问题的深意 |
| **Step 4** | 纠正错误答案 + 提供模型回答 | 错误回答提供正确答案 |

## 输出结构
最终生成一个 Markdown 格式的内容，包含 5 个模块：
1. 问题列表 — 全文所有提取出的问题，有序编号
2. 问题深意 — 每个关键问题的考察目的、深层意图、理想回答方向
3. 面试结果分析 — 正确率、分项评分（技术深度/解决问题/系统设计/沟通）、优劣势总结
4. 错误答案纠正 — 原回答 → 错误分析 → 正确答案 → 改进建议
5. 面试总结 — 按面试类型分支输出：
   - 技术面 → 「建议你重点补的内容」（To-Learn List）：按主题列出本次暴露的具体知识点
   - HR / 行为面 → 「综合建议」：个性化、可执行的编号建议
   - 混合面 → 两者都输出

## 使用方式
以后你拿着面试录音整理的文本，直接跟你的 Agent 工具说：

> 帮我安装这个 Skill [$interview-review](https://github.com/TheaWu7/interview-review-skill) ,安装好之后分析一下这段面试记录。
